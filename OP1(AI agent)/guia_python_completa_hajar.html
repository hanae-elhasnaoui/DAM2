1. Instalar y ejecutar

Instala Python desde python.org. En Windows marca Add Python to PATH. En VS Code instala la extensión Python de Microsoft.

python --version
python hola.py
# En algunos Windows: py hola.py

Los archivos terminan en .py. Un comentario empieza con #. Python usa la indentación (normalmente cuatro espacios) para crear bloques.

if 5 > 2:
    print("Dentro del if")
print("Siempre se ejecuta")

2. Variables, tipos e input

nombre = "Hajar"   # str: texto
edad = 21          # int: entero
nota = 8.5         # float: decimal
activo = True      # bool: True / False
vacio = None       # no hay valor
print(type(nota))
Muy importante: input() siempre devuelve texto. Convierte el valor si necesitas un número.
nombre = input("Nombre: ")
edad = int(input("Edad: "))
precio = float(input("Precio: "))
print(f"Hola {nombre}; tienes {edad} años")

Conversión: str(5), int("5"), float("2.5"). En Python el decimal usa punto: 2.5.

3. Operadores

  • Matemáticos: + - * / // % **. 7//2 es 3; 7%2 es 1; 2**3 es 8.
  • Comparación: == != > < >= <=.
  • Lógicos: and, or, not.
  • Asignación: = += -= *=. Ejemplo: contador += 1.
  • Pertenencia: in y not in.

Ojo: = asigna; == compara.

4. Condiciones: if, elif y else

nota = float(input("Nota: "))

if nota >= 9:
    mensaje = "Sobresaliente"
elif nota >= 7:
    mensaje = "Notable"
elif nota >= 5:
    mensaje = "Aprobado"
else:
    mensaje = "Suspendido"

print(mensaje)

Para comparar texto ignorando mayúsculas: nombre.lower() == "hajar".

5. Bucles

for: recorrer o repetir una cantidad

for numero in range(1, 6):  # 1 hasta 5
    print(numero)

nombres = ["Hajar", "Sara", "Ana"]
for indice, nombre in enumerate(nombres):
    print(indice, nombre)

while: repetir mientras se cumpla una condición

intentos = 0
while intentos < 3:
    clave = input("Clave: ")
    if clave == "1234":
        print("Acceso correcto")
        break
    intentos += 1
else:
    print("No quedan intentos")

break sale del bucle. continue salta a la vuelta siguiente.

7. Listas, tuplas, sets y diccionarios

Lista []: ordenada y modificable

notas = [7, 8, 6]
notas.append(9)
notas.insert(0, 10)
notas.remove(6)
ultima = notas.pop()
notas.sort()
print(notas[0], len(notas))

Tupla (): no modificable

coordenada = (43.26, -2.93)
latitud, longitud = coordenada

Set {}: sin valores repetidos

colores = {"rojo", "azul", "rojo"}
colores.add("verde")

Diccionario {clave: valor}: ficha de datos

alumna = {"nombre": "Hajar", "curso": "DAM2", "nota": 8}
print(alumna["nombre"])
print(alumna.get("telefono", "No existe"))
alumna["nota"] = 9
for clave, valor in alumna.items():
    print(clave, valor)
Regla: muchos valores iguales → lista. Datos de una persona/producto → diccionario. No cambiar → tupla. Sin repetidos → set.
numeros = [1, 2, 3, 4, 5]
cuadrados = [n ** 2 for n in numeros]
pares = [n for n in numeros if n % 2 == 0]

8. Funciones

Una función reúne una tarea. Recibe parámetros y puede devolver un resultado con return.

def sumar(numero1, numero2):
    resultado = numero1 + numero2
    return resultado

def saludar(nombre="persona"):
    print(f"Hola, {nombre}")

resultado = sumar(4, 6)
saludar("Hajar")

Imprimir no es devolver: una función con return deja guardar y reutilizar el resultado. Las variables creadas dentro de una función son locales.

9. Errores y excepciones

Lee siempre la última línea del error. SyntaxError: código mal escrito. TypeError: tipos incompatibles. ValueError: valor incorrecto.

try:
    edad = int(input("Edad: "))
    resultado = 10 / edad
except ValueError:
    print("Escribe un número entero")
except ZeroDivisionError:
    print("No puede ser cero")
else:
    print(resultado)
finally:
    print("Fin")

No uses except: vacío: escondería errores importantes.

10. Ficheros, JSON y CSV

# w escribe y borra anterior; a añade
with open("notas.txt", "w", encoding="utf-8") as archivo:
    archivo.write("Hajar;8\n")

with open("notas.txt", "r", encoding="utf-8") as archivo:
    for linea in archivo:
        print(linea.strip())

with cierra el fichero automáticamente. Modos: r leer, w escribir, a añadir, x crear si no existe.

import json
persona = {"nombre": "Hajar", "edad": 21}
with open("persona.json", "w", encoding="utf-8") as f:
    json.dump(persona, f, ensure_ascii=False, indent=4)
with open("persona.json", encoding="utf-8") as f:
    datos = json.load(f)
import csv
with open("alumnas.csv", "w", newline="", encoding="utf-8") as f:
    escritor = csv.writer(f)
    escritor.writerow(["nombre", "nota"])
    escritor.writerow(["Hajar", 8])

12. Programación orientada a objetos

Clase = molde. Objeto = elemento creado desde el molde. Atributos = datos. Métodos = acciones.

class Alumna:
    def __init__(self, nombre, curso, nota=0):
        self.nombre = nombre
        self.curso = curso
        self.nota = nota

    def aprobar(self):
        return self.nota >= 5

    def __str__(self):
        return f"{self.nombre} — {self.curso}: {self.nota}"

hajar = Alumna("Hajar", "DAM2", 8)
print(hajar.nombre)
print(hajar.aprobar())
print(hajar)

self significa “este objeto”. __init__ se ejecuta al crearlo. __str__ define cómo se muestra.

class Persona:
    def __init__(self, nombre):
        self.nombre = nombre

class Profesora(Persona):
    def saludar(self):
        return f"Hola, soy {self.nombre}"

13. Base de datos SQLite

import sqlite3

conexion = sqlite3.connect("instituto.db")
cursor = conexion.cursor()
cursor.execute("""CREATE TABLE IF NOT EXISTS alumna (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nombre TEXT NOT NULL,
    nota REAL NOT NULL
)""")
cursor.execute("INSERT INTO alumna (nombre, nota) VALUES (?, ?)", ("Hajar", 8.5))
conexion.commit()

cursor.execute("SELECT * FROM alumna WHERE nota >= ?", (5,))
for fila in cursor.fetchall():
    print(fila)
conexion.close()
Usa siempre ? en SQL con datos del usuario. No juntes texto del usuario directamente con la consulta.

14. APIs y requests

Una API permite pedir datos a otro servicio. GET lee, POST crea, PUT/PATCH actualiza y DELETE elimina.

import requests

try:
    respuesta = requests.get("https://api.example.com/products", timeout=10)
    respuesta.raise_for_status()
    productos = respuesta.json()
    print(productos)
except requests.RequestException as error:
    print("No se pudo conectar:", error)
Nunca subas contraseñas, tokens o claves API a GitHub. Guárdalos como variables de entorno o en .env (incluido en .gitignore).

15. Tests y buenas prácticas

# calculadora.py
def dividir(a, b):
    if b == 0:
        raise ValueError("No se puede dividir entre cero")
    return a / b

# test_calculadora.py
import unittest
from calculadora import dividir

class TestCalculadora(unittest.TestCase):
    def test_dividir(self):
        self.assertEqual(dividir(10, 2), 5)

if __name__ == "__main__":
    unittest.main()
python -m unittest

Usa nombres claros, funciones pequeñas, constantes en MAYÚSCULAS, evita repetir código, prueba errores y sigue PEP 8.
