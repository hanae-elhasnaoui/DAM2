1. ¿Qué es TypeScript?

TypeScript (TS) es JavaScript con tipos. Tú indicas qué dato esperas y el editor detecta muchos errores antes de ejecutar el programa. El navegador no ejecuta TS directamente: primero se convierte a JavaScript.

JavaScriptTypeScript
Flexible, pero puede fallar por un tipo incorrecto.Comprueba tipos mientras escribes.
let edad = "20";let edad: number = 20;

Crear y ejecutar un archivo

# Instalar TypeScript una vez
npm install -g typescript
tsc --version
# Convertir y ejecutar
tsc ejemplo.ts
node ejemplo.js
En Angular normalmente no necesitas ejecutar tsc: ng serve compila todo.

3. Funciones

Una función recibe datos (parámetros), hace una tarea y puede devolver un resultado. Después de los paréntesis indicamos el tipo de retorno.

function sumar(a: number, b: number): number {
  return a + b;
}
const resultado: number = sumar(4, 6);

function saludar(nombre: string): void {
  console.log(`Hola ${nombre}`);
}
function crearUsuario(nombre: string, edad?: number): string {
  return edad ? `${nombre} tiene ${edad}` : nombre;
}
function aplicarIva(precio: number, iva: number = 0.21): number {
  return precio * (1 + iva);
}
const multiplicar = (a: number, b: number): number => a * b;
void significa “no devuelve ningún valor”.

5. Clases: desde cero

Una clase es un molde. Un objeto es una cosa creada con ese molde. Coche es la clase; tu coche concreto es un objeto.

class Persona {
  nombre: string;
  edad: number;

  constructor(nombre: string, edad: number) {
    this.nombre = nombre;
    this.edad = edad;
  }

  presentarse(): string {
    return `Soy ${this.nombre} y tengo ${this.edad} años`;
  }
}
const hajar = new Persona("Hajar", 22);
console.log(hajar.presentarse());

Modificadores de acceso

PalabraAcceso
publicDesde cualquier lugar. Es el valor por defecto.
privateSolo dentro de la clase.
protectedDentro de la clase y sus clases hijas.
readonlySolo se asigna una vez.
class Cuenta {
  constructor(
    public titular: string,
    readonly iban: string,
    private saldo: number = 0
  ) {}

  ingresar(cantidad: number): void {
    if (cantidad > 0) this.saldo += cantidad;
  }
  verSaldo(): number { return this.saldo; }
}
const cuenta = new Cuenta("Hajar", "ES00", 100);
cuenta.ingresar(50);
console.log(cuenta.verSaldo()); // 150
// cuenta.saldo = 0; // error: private

Getters y setters

class Pelicula {
  constructor(public titulo: string, private _valoracion: number) {}
  get valoracion(): number { return this._valoracion; }
  set valoracion(nueva: number) {
    if (nueva >= 0 && nueva <= 10) this._valoracion = nueva;
  }
}

Herencia y abstract

abstract class Animal {
  constructor(protected nombre: string) {}
  abstract hacerSonido(): string;
}
class Perro extends Animal {
  hacerSonido(): string { return `${this.nombre}: guau`; }
}
const perro = new Perro("Luna");

Implementar una interfaz

interface Guardable { guardar(): void; }
class Nota implements Guardable {
  constructor(public texto: string) {}
  guardar(): void { console.log("Nota guardada"); }
}

6. TypeScript intermedio y avanzado

Uniones y narrowing

function mostrarId(id: string | number): string {
  if (typeof id === "string") return id.toUpperCase();
  return id.toFixed(0);
}

Generics: reutilizar sin perder el tipo

function primero<T>(lista: T[]): T | undefined {
  return lista[0];
}
const primerNumero = primero<number>([3, 7, 9]);
const primerNombre = primero<string>(["Hajar", "Ana"]);

interface RespuestaApi<T> { ok: boolean; datos: T; }
const respuesta: RespuestaApi<Producto[]> = { ok: true, datos: [teclado] };

Utility Types

TipoQué hace
Partial<T>Convierte todo en opcional
Pick<T,K>Escoge propiedades
Omit<T,K>Quita propiedades
Readonly<T>No deja modificar
Record<K,T>Objeto con claves y valores definidos
type NuevoProducto = Omit<Producto, "id">;
type CambiosProducto = Partial<Producto>;
const cambios: CambiosProducto = { precio: 25 };

Promesas y async/await

async function cargarProducto(id: number): Promise<Producto> {
  const respuesta = await fetch(`https://api.ejemplo.com/productos/${id}`);
  if (!respuesta.ok) throw new Error("No se pudo cargar el producto");
  return await respuesta.json() as Producto;
}

Módulos: separar archivos

// producto.ts
export interface Producto { nombre: string; precio: number; }
export function conIva(p: Producto): number { return p.precio * 1.21; }

// app.ts
import { Producto, conIva } from "./producto";

7. Lo que más usarás en Angular

// producto.ts (modelo)
export interface Producto {
  id: number;
  nombre: string;
  precio: number;
}

// lista.component.ts
export class ListaComponent {
  productos: Producto[] = [];
  cargando = false;

  agregar(producto: Producto): void {
    this.productos.push(producto);
  }
}

En Angular, los tipos hacen que componentes, servicios y respuestas de API tengan una estructura clara. Las interfaces normalmente van en una carpeta models.

8. Método para resolver ejercicios

  1. Identifica qué datos hay: texto, número, booleano u objeto.
  2. Crea primero los type o interface.
  3. Escribe funciones pequeñas con sus parámetros y retorno.
  4. Si hay estado y acciones relacionadas, crea una clase.
  5. Prueba con console.log().
  6. Corrige los errores rojos de TypeScript antes de seguir.
Ejercicio 1 · Función

Crea calcularDescuento(precio, porcentaje) que devuelva el precio final.

Ejercicio 2 · Interface + array

Define Tarea con id, titulo y completada. Crea un array y una función que cuente las completadas.

Ejercicio 3 · Clase

Crea Carrito con una lista privada de productos y métodos para agregar y calcular el total.

Ejercicio 4 · Herencia

Crea una clase abstracta Empleado con calcularSueldo(). Después crea EmpleadoFijo y EmpleadoPorHoras.

Errores frecuentes

  • Para comparar usa ===, no =.
  • Dentro de una clase no olvides this..
  • Si el valor cambia, usa let; si no cambia, const.
  • No uses any para ocultar errores.
  • El tipo que devuelve una función debe coincidir con su return.
Consejo final: si aparece un error, léelo: TypeScript normalmente te dice qué dato esperaba y cuál recibió.
