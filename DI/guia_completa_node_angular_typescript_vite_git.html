2. Node.js

Node.js permite ejecutar JavaScript fuera del navegador. Es la base para muchas herramientas del desarrollo frontend.

node -v

Comprueba la versión instalada.

3. npm

npm significa Node Package Manager. Sirve para instalar y administrar paquetes.

npm -v
npm install nombre-del-paquete

Los paquetes del proyecto suelen quedar en node_modules y sus dependencias se registran en package.json.

4. strict-ssl

En algunos entornos con proxies o certificados corporativos puede aparecer un problema SSL.

npm config set strict-ssl false
Precaución: desactivar esta comprobación reduce la seguridad. Si se usa como solución temporal, vuelve a activarla:
npm config set strict-ssl true

5. Angular CLI

Angular es un framework para aplicaciones web. Angular CLI es su herramienta de línea de comandos.

npm install -g @angular/cli
ng v

-g significa instalación global. ng v muestra información de la CLI.

6. Visual Studio Code

VS Code es el editor donde escribiremos el código.

Ctrl + Shift + P

La paleta de comandos permite buscar Configure Display Language para cambiar el idioma.

Extensiones útiles

  • Bracket Pair Colorization Toggler
  • Auto Close Tag
  • Angular Snippets

8. Git y GitHub

Git controla versiones. GitHub permite alojar repositorios Git y colaborar.

git --version
git config --global user.name "Tu Nombre"
git config --global user.email "tu-correo@ejemplo.com"
Usa tu nombre y correo reales al configurar tu propio Git. Los valores anteriores son solo ejemplos.

9. json-server

json-server crea rápidamente una API REST falsa a partir de JSON. Es útil para practicar frontend sin backend real.

npm install -g json-server

Ejemplo de datos:

{
  "usuarios": [
    { "id": 1, "nombre": "Ana" },
    { "id": 2, "nombre": "Luis" }
  ]
}

10. PowerShell

PowerShell es una terminal de Windows.

Get-ExecutionPolicy
Set-ExecutionPolicy Unrestricted
Importante: Unrestricted es permisivo. No lo cambies por costumbre; hazlo solo si el entorno o el curso lo requiere y entiende qué implica.

11. Vite

Vite proporciona un servidor de desarrollo rápido y herramientas de build para proyectos frontend.

Durante el desarrollo suele aparecer:

http://localhost:5173

localhost = tu propio ordenador. 5173 = puerto habitual de desarrollo de Vite.

12. TypeScript desde cero

TypeScript está basado en JavaScript y añade un sistema de tipos. Normalmente el código TypeScript se transforma a JavaScript para poder ejecutarse en el navegador.

TipoEjemploSignificado
string"Hola"Texto
number95Número
booleantrueVerdadero/falso
number | string95 o "FULL"Número o texto

13. Primer programa TypeScript

/*
01-basic-types.ts
COMENTARIO - PRIMER PROGRAMA
*/

let nombre: string = '2DAM';
let hp: number|string = 95;
let estaVivo: boolean = true;

console.log(hp);
hp = 'FULL';
console.log(nombre, hp, estaVivo);
console.log({nombre, hp, estaVivo});

Explicación

  • let nombre: string = '2DAM'; crea una variable de texto.
  • let hp: number|string = 95; permite número o texto: es un tipo unión.
  • let estaVivo: boolean = true; guarda verdadero/falso.
  • console.log(hp); muestra el valor en consola.
  • hp = 'FULL'; es válido porque hp admite number|string.
  • console.log({nombre, hp, estaVivo}); muestra un objeto usando propiedades abreviadas.

La última línea equivale aproximadamente a:

console.log({
  nombre: nombre,
  hp: hp,
  estaVivo: estaVivo
});

14. Guía práctica completa

Paso 1 — Comprobar Node y npm

node -v
npm -v

Paso 2 — Angular CLI, si lo necesitas

npm install -g @angular/cli
ng v

Paso 3 — Git

git --version
git config --global user.name "Tu Nombre"
git config --global user.email "tu-correo@ejemplo.com"

Paso 4 — json-server, si el curso lo usa

npm install -g json-server

Paso 5 — Crear proyecto Vite

npm create vite@latest

Selecciona Vanilla y después TypeScript.

Paso 6 — Entrar, instalar y arrancar

cd nombre-del-proyecto
npm install
npm run dev

Paso 7 — Abrir el navegador

http://localhost:5173
Objetivo: tener un proyecto TypeScript funcionando, poder editar el código y ver los cambios desde el navegador.
