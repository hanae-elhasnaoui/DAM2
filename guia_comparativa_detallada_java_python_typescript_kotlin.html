1. La idea fundamental

Los cuatro lenguajes permiten resolver problemas similares, pero pertenecen a ecosistemas diferentes.

Java
JVM + backend + sistemas empresariales Python
automatización + datos + IA + backend TypeScript
web + JavaScript + frontend/backend Kotlin
JVM + Android + backend moderno
Idea clave: no debes aprenderlos como cuatro mundos completamente separados. Variables, condiciones, bucles, funciones, clases y algoritmos son conceptos transferibles. Lo que cambia es la sintaxis y las reglas concretas.

3. ¿Cómo se ejecuta cada lenguaje?

Java

El código Java se compila normalmente a bytecode, que es ejecutado por la JVM (Java Virtual Machine).

Java
  ↓
Compilador javac
  ↓
Bytecode (.class)
  ↓
JVM
  ↓
Programa ejecutándose

Python

Python tiene un modelo de ejecución gestionado por su runtime. En implementaciones habituales existe una fase de compilación a bytecode interno y después ejecución mediante la máquina virtual de Python.

Python
  ↓
Runtime de Python
  ↓
Bytecode interno / VM
  ↓
Programa

TypeScript

TypeScript no se ejecuta normalmente directamente en el navegador. Se transforma a JavaScript y ese JavaScript se ejecuta en el navegador o en un runtime como Node.js.

TypeScript
  ↓
Compilador / herramienta
  ↓
JavaScript
  ↓
Navegador o runtime JS

Kotlin

Kotlin puede compilar a bytecode JVM, aunque también existen otros destinos según la plataforma.

Kotlin
  ↓
Compilador Kotlin
  ↓
Bytecode JVM
  ↓
JVM / Android

4. Java en detalle

Variables y tipos

String nombre = "Ana";
int edad = 20;
double altura = 1.75;
boolean activo = true;

Características importantes

  • Tipado estático.
  • Clases y objetos son fundamentales.
  • Amplio ecosistema empresarial.
  • JVM como plataforma principal.
  • Gestión automática de memoria.
  • Gran cantidad de frameworks y librerías.

Herramientas típicas

JDK, Maven, Gradle, IntelliJ IDEA, Eclipse, Spring y otros frameworks del ecosistema Java.

5. Python en detalle

Variables

nombre = "Ana"
edad = 20
altura = 1.75
activo = True

Características importantes

  • Tipado dinámico.
  • La indentación forma parte de la estructura del código.
  • Sintaxis normalmente corta y legible.
  • Amplísimo ecosistema para datos, IA y automatización.
  • Muy útil para scripts y prototipos.

Herramientas

Python, pip, venv, PyCharm, VS Code y múltiples frameworks y librerías.

6. TypeScript en detalle

Variables

let nombre: string = "Ana";
let edad: number = 20;
let activo: boolean = true;

Inferencia de tipos

let edad = 20;
// TypeScript infiere que edad es number

Uniones

let hp: number | string = 95;

hp = "FULL"; // también permitido

Características

  • Se apoya en JavaScript.
  • Añade tipos estáticos y herramientas de análisis.
  • Excelente para proyectos web grandes.
  • Angular utiliza TypeScript como lenguaje principal.
  • Funciona con el ecosistema npm.

7. Kotlin en detalle

Variables

val nombre: String = "Ana"
var edad: Int = 20
val activo: Boolean = true

val y var

  • val: referencia que no se reasigna después de inicializarse.
  • var: variable que puede reasignarse.

Características

  • Tipado estático con inferencia.
  • Sintaxis concisa.
  • Null safety.
  • Interoperabilidad con Java.
  • Muy importante en Android.

9. Variables y constantes

// Java
int edad = 20;
final int MAX = 100;

// Python
edad = 20
MAX = 100  # convención, no constante real del lenguaje

// TypeScript
let edad: number = 20;
const MAX: number = 100;

// Kotlin
var edad: Int = 20;
val MAX: Int = 100

Una diferencia importante: en Kotlin val impide reasignar la referencia; en TypeScript const impide reasignar la variable. Java utiliza final.

11. Condicionales

// Java
if (edad >= 18) {
    System.out.println("Adulto");
} else {
    System.out.println("Menor");
}

// Python
if edad >= 18:
    print("Adulto")
else:
    print("Menor")

// TypeScript
if (edad >= 18) {
    console.log("Adulto");
} else {
    console.log("Menor");
}

// Kotlin
if (edad >= 18) {
    println("Adulto")
} else {
    println("Menor")
}
Observa: Python utiliza indentación. Java, TypeScript y Kotlin utilizan normalmente llaves para delimitar bloques.

12. Bucles

For tradicional

// Java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

// Python
for i in range(5):
    print(i)

// TypeScript
for (let i = 0; i < 5; i++) {
    console.log(i);
}

// Kotlin
for (i in 0 until 5) {
    println(i)
}

Recorrer colecciones

// Java
for (String nombre : nombres) {
    System.out.println(nombre);
}

// Python
for nombre in nombres:
    print(nombre)

// TypeScript
for (const nombre of nombres) {
    console.log(nombre);
}

// Kotlin
for (nombre in nombres) {
    println(nombre)
}

17. Programación orientada a objetos

La POO organiza el programa alrededor de clases, objetos, atributos y métodos.

Clase sencilla

// Java
class Persona {
    String nombre;

    Persona(String nombre) {
        this.nombre = nombre;
    }

    void saludar() {
        System.out.println("Hola " + nombre);
    }
}

// Python
class Persona:
    def __init__(self, nombre):
        self.nombre = nombre

    def saludar(self):
        print("Hola", self.nombre)

// TypeScript
class Persona {
    constructor(public nombre: string) {}

    saludar(): void {
        console.log(`Hola ${this.nombre}`);
    }
}

// Kotlin
class Persona(val nombre: String) {
    fun saludar() {
        println("Hola $nombre")
    }
}

18. Interfaces y abstracción

Java

interface Animal {
    void hacerSonido();
}

TypeScript

interface Animal {
    nombre: string;
    hacerSonido(): void;
}

Kotlin

interface Animal {
    val nombre: String
    fun hacerSonido()
}

Python

Python puede conseguir abstracciones mediante clases base abstractas, protocolos y otras técnicas.

from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def hacer_sonido(self):
        pass

19. Herencia y polimorfismo

// Java
class Animal {
    void sonido() {
        System.out.println("Sonido");
    }
}

class Perro extends Animal {
    @Override
    void sonido() {
        System.out.println("Guau");
    }
}

// TypeScript
class Animal {
    sonido(): void {
        console.log("Sonido");
    }
}

class Perro extends Animal {
    override sonido(): void {
        console.log("Guau");
    }
}

// Kotlin
open class Animal {
    open fun sonido() {
        println("Sonido")
    }
}

class Perro : Animal() {
    override fun sonido() {
        println("Guau")
    }
}

Python también permite herencia mediante:

class Perro(Animal):
    def sonido(self):
        print("Guau")

20. Genéricos

Los genéricos permiten escribir código reutilizable manteniendo información de tipos.

// Java
List<String> nombres;

// TypeScript
const nombres: Array<string> = [];

// Kotlin
val nombres: List<String> = listOf()

// Python
from typing import List
nombres: List[str] = []
En Python las anotaciones de tipos sirven principalmente para análisis estático y herramientas; no convierten automáticamente el lenguaje en un sistema de tipos estático como Java.

23. Asincronía y concurrencia

TypeScript

async function cargarUsuarios() {
    const respuesta = await fetch("/api/usuarios");
    const usuarios = await respuesta.json();
    return usuarios;
}

Python

async def cargar_usuarios():
    usuarios = await obtener_usuarios()
    return usuarios

Kotlin

suspend fun cargarUsuarios(): List<Usuario> {
    return obtenerUsuarios()
}

Java

Java dispone de hilos, ejecutores, futuros y APIs de concurrencia, entre otros mecanismos.

ExecutorService executor =
    Executors.newFixedThreadPool(2);
No confundas: asincronía, concurrencia y paralelismo están relacionados pero no significan exactamente lo mismo.

25. Memoria y garbage collection

Los cuatro ecosistemas modernos gestionan gran parte de la memoria automáticamente, aunque los detalles son diferentes.

LenguajeGestión
JavaGarbage Collector de la JVM
PythonConteo de referencias y mecanismos de garbage collection en implementaciones habituales como CPython
TypeScriptDepende del runtime JavaScript, como navegador o Node.js
Kotlin/JVMGarbage Collector de la JVM

Esto significa que normalmente no tienes que liberar manualmente cada objeto como se haría en lenguajes con gestión manual de memoria.

30. Rendimiento

No es correcto reducir la comparación a “lenguaje rápido” frente a “lenguaje lento”. El rendimiento depende del runtime, algoritmo, librerías, arquitectura y carga.

FactorQué debes mirar
AlgoritmosComplejidad temporal y espacial.
RuntimeJVM, Python runtime, JavaScript runtime, etc.
MemoriaAsignaciones, objetos y garbage collection.
I/ORed, disco, base de datos.
FrameworkPuede influir mucho en una aplicación real.
Para estudiar: primero aprende algoritmos y estructuras de datos. Comparar solo la velocidad de la sintaxis de los lenguajes puede llevar a conclusiones incorrectas.

33. Mini proyecto comparativo

Problema: crear un programa que guarde usuarios y permita mostrar su nombre y edad.

Java

class Usuario {
    String nombre;
    int edad;

    Usuario(String nombre, int edad) {
        this.nombre = nombre;
        this.edad = edad;
    }

    void mostrar() {
        System.out.println(nombre + " - " + edad);
    }
}

public class Main {
    public static void main(String[] args) {
        Usuario usuario = new Usuario("Ana", 20);
        usuario.mostrar();
    }
}

Python

class Usuario:
    def __init__(self, nombre, edad):
        self.nombre = nombre
        self.edad = edad

    def mostrar(self):
        print(self.nombre, "-", self.edad)

usuario = Usuario("Ana", 20)
usuario.mostrar()

TypeScript

class Usuario {
    constructor(
        public nombre: string,
        public edad: number
    ) {}

    mostrar(): void {
        console.log(`${this.nombre} - ${this.edad}`);
    }
}

const usuario = new Usuario("Ana", 20);
usuario.mostrar();

Kotlin

class Usuario(
    val nombre: String,
    val edad: Int
) {
    fun mostrar() {
        println("$nombre - $edad")
    }
}

fun main() {
    val usuario = Usuario("Ana", 20)
    usuario.mostrar()
}

La idea más importante

Los cuatro lenguajes comparten fundamentos: variables → condiciones → bucles → funciones → estructuras de datos → objetos → errores → módulos → aplicaciones.

Cuando aprendes un lenguaje, no solo estás memorizando palabras. Estás aprendiendo a resolver problemas. Después, aprender otro lenguaje consiste en aprender cómo expresa esos mismos conceptos y qué herramientas aporta su ecosistema.

Nota: esta comparación es descriptiva y no pretende establecer un ganador general. Un lenguaje puede ser adecuado para una tarea y menos adecuado para otra.
